Local editing only. “Published” includes an article in the website export when the Notes section is enabled. Your live website changes only when that export is deployed.

Use ## for headings, **bold**, - for lists, [label](https://…) for sources, and ![description](/assets/…) for images. Uploading inserts an image at your cursor and fills an empty cover field. Raw scripts and unsafe HTML are removed.

How to add an academic entry

Place entries inside the matching list below. Each entry supports title, date, venue, description and url. Use a DOI or a link to a hosted PDF for publications; use a hosted CV link for CV. Keep all five lists, even when empty.

{ "title": "Your paper title", "date": "2027", "venue": "Journal name", "description": "Authors and a brief description", "url": "https://doi.org/..." }
